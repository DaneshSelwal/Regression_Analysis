# Contributing to Regression Uncertainty Quantification Analysis

First off, thanks for taking the time to contribute! 🎉

## How to Contribute

### Reporting Bugs
If you find a bug, please open an issue and include:
- A clear, descriptive title.
- Steps to reproduce the issue.
- Your environment details (OS, Python version).

### Suggesting Enhancements
Enhancement suggestions are welcome! Please open an issue and explain why the enhancement would be useful.

### Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or fix.
3. Ensure your notebooks are cleared of output before committing (optional but recommended).
4. Submit a pull request to the `version1.2` branch.

## Environment Setup
It is recommended to use Google Colab or a local Python 3.10+ environment with `conda` or `venv`.
